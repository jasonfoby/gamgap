# 분석 연동 · 환불 가이드 강화 기록 (2026-09-12)

## 분석 — Google Analytics 4

**왜 GA4인가.** 알고 싶은 것은 "사람이 다시 오는가"와 "찜·게임 조회·스팀 이동을 하는가"다.
Cloudflare Web Analytics는 쿠키 없는 페이지뷰 집계라 재방문도 커스텀 이벤트도 잴 수 없다.
GA4는 재방문 사용자와 이벤트를 기본으로 보여주고, 같은 구글 계정의 서치 콘솔과 연결하면
"어떤 검색어로 들어와 무엇을 했는지"를 한곳에서 볼 수 있다. 동의 모드 v2 배선
(`index.html` consent default, `src/lib/consent.js` update)이 이미 있어 추가 법적 장치가 필요 없다.

**발견.** CLAUDE.md에는 "Cloudflare Web Analytics 자동 설정"이라 적혀 있었지만, 라이브 6개 경로
어디에도 비콘이 없었다. GA4 설정도 없었고 `track()`은 콘솔에만 찍는 빈 껍데기였다.
즉 이 작업 이전까지 사이트에는 방문 분석이 전혀 없었다.

**켜는 법(사용자 작업).**
1. analytics.google.com 에서 GA4 속성을 만들고 웹 스트림(lowstamp.com)을 추가해 측정 ID(`G-…`)를 받는다.
2. Cloudflare Pages → 설정 → 환경 변수에 `VITE_GA_MEASUREMENT_ID = G-…` 를 넣고 다시 배포한다.
   (또는 ID를 알려주면 코드에 넣어 커밋해도 된다. 측정 ID는 페이지 소스에 노출되는 공개값이다.)
3. GA4 관리 → 제품 링크 → Search Console 연결.

**수집 이벤트.** `page_view`(경로 변경마다) · `game_view` · `wishlist_add` / `wishlist_remove` ·
`steam_click` · `search_zero`.

**한계.** 쿠키 배너가 지역 구분 없이 모두에게 뜨고 기본값이 '거부'다. 그래서 재방문 사용자 수는
'동의'를 누른 사람 기준으로만 정확하고, 나머지는 쿠키 없는 익명 신호(구글 모델링)로 잡힌다.
동의가 법적으로 필수인 곳은 사실상 유럽(EEA)뿐이라 지역별로 기본값을 다르게 둘 수도 있지만,
이건 법적 판단이라 이번 작업에서는 바꾸지 않았다.

**개인정보처리방침 5항**을 6개 언어 모두 갱신했다(Google Analytics 명시, 동의 시에만 쿠키 저장,
철회 방법, Google 방침 링크). 갱신일 2026-09-12.

## 환불 가이드 강화

서치 콘솔 3개월 노출의 91%가 `/guide/steam-refund-policy` 한 편에서 나왔고, 검색어는 전부 영어였다.
구글봇은 Accept-Language 없이 수집하므로 Pages 함수가 **영어판**을 내보낸다 — 그래서 영어판이 1순위다.

- **첫 줄 결론**: 8월 말 재작성 때 이미 되어 있었다("The short answer first: …").
- **규칙 표**(`table` 블록 신설): 게임·사전 구매 2종·DLC·게임 내 아이템·지갑·번들·구독·환불 불가 9행.
  값은 기존 본문(8/29 스팀 공식 페이지 확인분)에서만 옮겼다.
- **FAQ**(`faq` 블록 신설): 기존 "Questions that come up a lot" 목록을 질문·답 구조로 바꾸고,
  서치 콘솔 검색어 문장("how long does a steam refund take", "steam refund after 2 hours",
  "steam refund pre order" 등)에 맞춰 질문 8개로 정리했다.
- **구조화 데이터**: 모든 가이드에 `Article`, faq 블록이 있는 글에 `FAQPage` JSON-LD를 head에 붙인다.
  ⚠ 구글은 2023년 8월부터 FAQ 리치 결과를 정부·보건 사이트로 제한했다. 검색 결과에 질문이
  펼쳐지는 효과는 기대하지 말 것. 실효는 "검색어와 같은 문장의 질문이 본문 소제목으로 있는 것"에서 난다.

**적용 언어**: 영어·한국어만. **일본어·중국어·스페인어·포르투갈어 환불 가이드에는 표와 FAQ 블록이 아직 없다.**
옮길 때는 위 영어판 표·FAQ를 그대로 번역하면 된다(블록 구조 동일).

**인접 정책 가이드는 만들지 않았다.** 사전 구매·DLC·환불 소요 시간 같은 주제는 이미 이 글의 절로
있다. 따로 얇은 글을 만들면 유일하게 순위가 나오는 이 페이지와 같은 검색어를 두고 서로 경쟁한다.
대신 FAQ로 검색어 변형을 이 한 페이지에 모았다.
