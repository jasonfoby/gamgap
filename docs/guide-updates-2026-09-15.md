# 가이드 보강 · 세일 알림 기록 (2026-09-15)

## 세일 일정 가이드 (`steam-sale-calendar`, 한국어)
- 첫 문단(결론) 바로 뒤에 `sale-reminder` 블록: 다음 확정 세일과 "캘린더에 알림 추가" 버튼.
- 네 줄짜리 일정 목록을 **한국 시간 기준 표**로 바꿨다. 요일은 `Intl`(Asia/Seoul)로 계산해 확인했다.
- 행동 버튼(`cta`) 1개, 자주 묻는 질문 8개("2026년 9월에 스팀 세일 있나요?", "가을 세일 몇 시에 시작" 등).
- **다른 언어는 그대로.** 영어판은 날짜가 정확하지만 표·FAQ·알림 카드는 없다.

## 가족 공유 가이드 (`steam-family-sharing`, 한국어 · 영어)
기존 글이 2024년 3월 이전의 옛 방식을 설명하고 있었다. 스팀 고객지원 공식 FAQ
"Steam Families"(help.steampowered.com/en/faqs/view/054C-3167-DD7F-49D4, 2026-09-15 확인)로 고쳤다.
- 틀렸던 것: "게임 주인이 게임을 켜면 빌린 사람이 나가야 한다" → 지금은 게임 한 카피당 한 명, 서로 다른 게임은 동시에 가능.
- 틀렸던 것: "친한 친구끼리" 권유 → 공식적으로 한집에 사는 최대 6명의 가까운 가족용. 나가면 1년 제한, 빈자리도 1년.
- 모호했던 것: "스팀 설정 안의 가족 메뉴" → 상점 계정 정보(Account Details) → 가족 관리(Family Management).
- 새로 넣은 것: 한눈에 보기 표, 같은 게임 동시 플레이 설명(공식 포털 2·하프라이프 예시), 공유 불가 조건, 1년 규칙, 만드는 순서, 행동 버튼, 자주 묻는 질문 9개.
- **일본어·중국어·스페인어·포르투갈어판에는 옛 설명이 그대로 남아 있다.** 영어판을 기준으로 옮기면 된다.

## 세일 알림(캘린더 파일)
- `src/lib/saleIcs.js`: 확정 세일을 `.ics` 파일로 만들어 내려받게 한다. 계정·이메일·서버 없이 방문자 자신의
  달력이 세일 시작 1시간 전에 알려준다. 규격(RFC 5545)에 맞춰 CRLF 줄바꿈, 75바이트 줄 접기, 쉼표·세미콜론 이스케이프.
- 쓰는 곳: 홈 사이드바 카운트다운(`SaleCountdown`)과 가이드 본문 `sale-reminder` 블록(`SaleReminder`).
- **추정 일정에는 버튼을 보이지 않는다**(틀린 날 알림이 울리면 안 되므로). 진행 중인 세일에도 안 보인다.
- 문구 키 `cd.addCalendar`·`cd.calTitle`·`cd.calDesc` 6개 언어. 분석 이벤트 `calendar_add`.

## 새 블록 타입
- `cta` { text, label, to } — 글 흐름 안의 버튼. 사이트 안 경로만. 이벤트 `guide_cta_click`. 봇용 본문에는 문단 + 링크.
- `sale-reminder` — 위 알림 카드. 봇용 본문에는 그리지 않는다.
