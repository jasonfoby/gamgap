# 한국어 문구 검수 기록 (2026-09-07)

한국어(`web/src/i18n/ko.js`)만 먼저 손봤습니다. **영어·일본어·중국어·스페인어·포르투갈어는 아직
그대로**라, 나중에 같은 판단을 그 다섯 언어에 옮길 때 이 문서를 보고 따라가면 됩니다.

각 항목은 "무엇을 / 왜" 순서로 적었습니다. 왜를 남긴 이유는, 다른 언어에서는 같은 문제가
다른 모양으로 나타나기 때문입니다. 예를 들어 조사 오류는 한국어에만 있는 문제지만,
"말투가 혼자 튄다"는 문제는 모든 언어에 있습니다.

---

## 1. 이미 6개 언어에 적용된 것 (이 검수 이전 작업)

- **히어로 제목** `hero.title` / `hero.titleHl` — "이 게임, 지금 사도 돼?"에서
  "스팀 게임, 지금이 **최저가**인지 알려드려요"로. 방문자가 보는 건 게임 하나가 아니라
  목록이라 "이 게임"이 가리킬 대상이 화면에 없었습니다. 금색 강조도 "지금"에서 "최저가"로
  옮겨, 금색이 '기록상 최저가' 한 가지 뜻만 갖는 원칙과 맞췄습니다.
- **히어로 부제** `hero.sub` — 제목과 동사가 겹치던 것을 정리하고 "이 게임"을 걷어냈습니다.
- **평가 9단계** `review.*` — 문구는 그대로, 색만 9단계로 분리(코드 변경).
- **새 키** `gp.seriesTitle` "같은 시리즈" — 아래 3번 참고.
- **삭제된 키** `card.series` / `card.seriesWhy` / `card.seriesCollapse` — 아래 3번 참고.

## 2. 이번에 한국어만 바꾼 것 (나머지 5개 언어 대기)

| 키 | 전 | 후 | 왜 |
|---|---|---|---|
| `footer.tagline` | …비교해서 **살 때인지** 알려드려요 | …비교해서, 지금 **구매해도 좋은지** 알려드려요 | "살 때인지"가 시장 상인 말투처럼 읽힘 |
| `lows.error` | 불러오지 못했**습니다** | 불러오지 못했**어요** | 사이트 전체가 해요체인데 이 한 줄만 합니다체 |
| `cookie.text` | Lowstamp**은** …사용**합니다** | Lowstamp**는** …사용**해요** | 조사 오류(받침 없음) + 말투 통일 |
| `sort.depth` | 최저 **근접** 순 | 최저가**에 가까운** 순 | 딱딱한 한자어 |
| `ctrl.onlyLow` · `chip.onlyLow` | 최저만 | 최저**가**만 | 뭐가 최저인지 안 드러남 |
| `tab.lowest` | 오늘**의** 최저가 | 오늘 최저가 | 같은 걸 가리키는데 화면마다 표기가 달랐음(`home.lowestTitle`·`header.badge`는 "오늘 최저가") |
| `author.by` | 글 {name} | **글쓴이** {name} | 축약이 어색 |
| `page.updated` | **최종** 수정 {d} | **마지막** 수정 {d} | 쉬운 일상어 |

다른 언어에 옮길 때: 표의 "왜"가 그 언어에도 해당하는지부터 보세요. 조사 오류(3행)는
한국어 전용이고, 말투 통일(2·3행)과 용어 통일(6행)은 다섯 언어 모두에 해당합니다.

## 3. 코드 변경 — 시리즈 묶음 (언어 무관)

목록에서 "같은 가격 시리즈 5개 더 보기" 버튼으로 접었다 펴던 것을 없앴습니다. 방문자가
그 표시의 뜻을 알기 어려웠기 때문입니다. 대신 **목록에는 대표 한 장만** 두고, 접힌 나머지는
그 게임의 **상세 페이지 "같은 시리즈" 섹션**에서 링크로 이어 보게 했습니다.

검색 노출은 그대로입니다. 사이트맵은 워커의 `/api/appids`로 만들어져 목록 UI와 무관하고,
묶인 게임들도 각자 `/game/:appid` 페이지를 그대로 갖습니다. 오히려 상세 페이지에 내부 링크가
생겨 크롤러가 따라갈 길이 하나 늘었습니다.

관련 파일: `web/src/lib/series.js`(펼치기 상태 제거), `web/src/components/GameCard.jsx`(스트립 제거),
`web/src/pages/GamePage.jsx`(`useSeriesSiblings` + `SeriesList` 추가), `web/src/pages/GamePage.css`.

## 4. 버그 수정 — 원화 소수점

`web/src/lib/format.js`의 `won()`이 `toLocaleString`을 그냥 쓰고 있어서, 평균가처럼
나눗셈으로 생긴 값이 **"785.714원"**으로 나왔습니다. 주석에는 "통화별 자릿수는 Intl이 처리"라고
적혀 있었지만 원화 경로는 Intl 통화 서식을 타지 않습니다. `Math.round`로 정수를 맞췄습니다.
이건 언어와 무관하게 원화를 쓰는 모든 화면에 해당됩니다.

## 5. 손대지 않기로 한 것

- **개인정보처리방침·이용약관의 합니다체**(`content/pages/ko/privacy.js` 25곳,
  `terms.js` 11곳). 나머지 화면과 가이드 22편은 전부 해요체지만, 한국어에서 법적 고지는
  격식체가 관례라 일부러 남겼습니다. 소개(`about.js`)·문의(`contact.js`)는 이미 해요체입니다.
- **`preset.u10` "1만원 이하"의 띄어쓰기** — 관용 표기라 그대로.

## 6. 아직 결정이 필요한 것 (사용자 확인 대기)

아래는 시그니처 문구이거나 검색 노출에 영향이 있어 임의로 바꾸지 않았습니다.

1. **판정 7단계 보조 문구**(`verdict.*.sub`) — "살 때예요 / 사도 좋아요 / 사도 무난해요"가
   등급 차이를 잘 못 드러내고, 명사형 "살 때"가 푸터에서 지적된 것과 같은 어색함을 갖습니다.
2. **`verdict.near.label` "거의 최저가" · `verdict.recent.label` "최근 최저가 수준"** —
   "최근 최저가"가 무슨 뜻인지 모호합니다(실제 로직은 최저가 +15% 이내).
3. **`meta.defaultTitle` "…지금 사도 돼?"** — 사이트 전체가 존댓말인데 여기만 반말입니다.
   검색 결과에 노출되는 제목이라 바꾸면 순위가 흔들릴 수 있어 보류했습니다.
4. **신뢰 배너**(`trust.officialK` "살 때인지 아닌지" / `trust.officialV` "최저가 기준으로 판단") —
   "판단"이 딱딱하고, 여기에도 "살 때"가 남아 있습니다.
5. **통계 라벨**(`stats.avg` "기록 평균가" · `stats.max` "기록 최고가") — 바로 아래 본문은
   "가장 비쌌을 때는"이라고 풀어 쓰는데 라벨은 한자어라 서로 안 맞습니다.
6. **`wish.note` · `wish.empty` · `meta.gameDesc`에 남은 "살 만한 / 살 때"** — 1번과 같은 사안.
